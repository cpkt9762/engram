# Engram

每个工作区右上角提供同步按钮；手机和窄窗口由 Paseo 收进工作区「···」菜单。未加入时显示「加入同步」，加入后显示「已同步」，菜单可停止同步、打开记忆面板或查看同步状态。这里的「已同步」表示本机已加入，不保证所有内容已经上传。项目有歧义时打开记忆面板选择；服务离线、版本过旧或未配置云同步时显示对应状态。

点击加入后，popover 先显示完整扫描进度。没有疑似项就直接加入并关闭；有疑似项时可逐条确认删除、重新扫描后加入、仍然加入或先不加入。扫描只覆盖 prompt，可能漏检，不检查记忆正文，也不承诺检测到所有秘密值。请求超时先查询实际状态，不自动重发写请求。

停止同步需要再次确认项目和宿主。停止后新记录不再进入上传队列，已有积压保留但暂停上传；其他机器的变更仍会拉取并应用，已上传的云端内容不会删除。重新加入会补推停止期间新建的记忆，但不会自动补推停止期间对已上传、已确认的同项目记忆所作的修改。已发出的同步请求可能仍会完成，保留的积压可能使同步状态显示阻塞。

记忆面板顶部复用同一组同步操作，提供搜索、最近记忆、打码的最近 prompt 和疑似项筛选。prompt 不提供原文查看。删除受项目和本地实例约束；已加入项目的删除会同步到其他机器，未加入项目的删除标记会在以后加入时带上。

需要 Paseo 0.13 或更新版本（已在 0.14.0 上验证），以及提供 `sync-admin-v2` 的 engram serve。只有 v1 时仍可查看加入状态，但停止项禁用并提示版本太旧；未加入的项目也不能通过新版按钮加入。按钮在注册、点击、操作后和每 60 秒刷新，同项目的并发检查和操作会合并。插件卸载后注销所有按钮和工作区订阅。

按钮只订阅普通工作区，不请求后台工作区功能，因此不依赖宿主的 `backgroundWorkspaces` 功能声明。订阅及翻页均按协议上限每页 200 个工作区，超过后继续按游标获取完整列表。订阅、分页快照和刷新错误在应用日志中记录分类码与错误信息，整条日志最多 200 字符；不记录错误对象、堆栈或请求内容，凭据/显式 prompt 字段会清理。真实多宿主订阅和桌面/手机按钮呈现仍需在宿主中确认，假 SDK 测试只覆盖已建模的协议行为。

侧边栏每 30 秒读取当前所选宿主的同步状态。绿色只说明传输状态，不证明内容没有被旧客户端覆盖；保留的 dead 记录单独归黄，展开后显示数量与人工查看说明，持续故障仍优先红。

主机设置只有 `engram.baseUrl`，默认 `http://127.0.0.1:7437`。只接受 loopback HTTP，拒绝重定向。鉴权读取 daemon 环境的 `ENGRAM_HTTP_TOKEN`，不保存到设置或传给客户端。插件属于可信代码，经 Paseo 配对的客户端和手机具有相同的删除、加入和停止权限。正式安装和实际桌面/手机按钮、菜单及 popover 验收由编排者进行。

已加入的项目最近被云端白名单拒绝时，按钮显示红色错误图标和「云端未放行」，可停止同步或查看状态；面板和侧边栏列出项目并提示需要在云端服务器白名单中加入。它记录最近一次拒绝，不是实时权限查询；放行后按现有退避等待下一次成功推送确认，停止同步后清除该项目提示。插件不会修改云端白名单或重试规则。

展示扫描会检查关键词后的显式赋值和 60 个 Unicode 字符内的疑似值。中文「密码/口令」后仅隔空白或「是/为/:/=/：」的 ASCII 可见串至少四字符即遮蔽，包括纯字母值；英文仍需显式连接词或密码形态，因此 password policy、token budget、secret key 不遮。附近疑似值需至少六字符且含字母与数字或特殊符号；关键词后 600 个 Unicode 字符内的单行 ASCII 回复（6–64 字符且同时含字母与数字，可带 [User]、[用户]、User: 等前缀）也遮蔽。明显 URL/路径除外，命中后整值替换。该规则共用于普通打码列表、扫描和错误文本，不修改存储原文；没有关键词的单行词、项目名与架构名不因形状被遮。
